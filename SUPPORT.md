# Support

*The English text is authoritative. Русская версия - ниже.*

**The project is in design and nothing is released yet.** There is no package to install and
no runtime to debug. Questions about how to use Funora do not have answers yet.

| I want to… | Go to |
|---|---|
| Report a bug in released code | the `bug` form in the relevant repository |
| Report that FunPay's pages changed and parsing broke | the `protocol-breakage` form |
| Report a security problem or a leaked key | [SECURITY.md](SECURITY.md) - **not** a public issue |
| Propose a feature or discuss design | Discussions in [Funora](https://github.com/Funora-Develop/Funora) |
| Follow progress | the repository list on the [organization page](https://github.com/Funora-Develop) |

This project is maintained by one person in their own time. Please do not expect same-day
responses, and do not open duplicate issues to get attention.

We cannot help with FunPay itself - account suspensions, payouts, disputes with buyers. Those
go to FunPay support.

# Поддержка

**Проект в стадии проектирования, ничего ещё не выпущено.** Устанавливать нечего, отлаживать
нечего. На вопросы «как пользоваться» ответов пока нет.

| Хочу… | Куда |
|---|---|
| Сообщить о баге в выпущенном коде | форма `bug` в нужном репозитории |
| Сообщить, что FunPay изменил страницы и парсинг сломался | форма `protocol-breakage` |
| Сообщить об уязвимости или об утечке ключа | [SECURITY.md](SECURITY.md) - **не** публичный issue |
| Предложить функцию или обсудить архитектуру | Discussions в [Funora](https://github.com/Funora-Develop/Funora) |
| Следить за развитием | список репозиториев на [странице организации](https://github.com/Funora-Develop) |

Проект ведёт один человек в свободное время. Не ждите ответа в тот же день и не заводите
дубликаты issue, чтобы привлечь внимание.

С самой FunPay помочь не можем - блокировки, выплаты, споры с покупателями решаются через
поддержку площадки.
